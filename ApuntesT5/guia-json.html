Apuntes y Guía de Examen: jQuery, JSON y AJAX

1. JSON (Intercambio de datos)

Anotación de examen: JSON es texto plano estructurado como mapa clave-valor. Solo admite: cadenas de texto, números, objetos, arrays, booleanos y null.
  • Serialización: Convierte un objeto JS a texto JSON para enviarlo. Función: JSON.stringify(objeto).
  • Deserialización: Convierte el texto JSON de vuelta a objeto JS para usar sus datos. Función: JSON.parse(texto_json).
let miObjeto = {
    nombre: "Ana",
    edad: 22
};

// 1. SERIALIZACIÓN: De Objeto a Texto
let textoJSON = JSON.stringify(miObjeto);
console.log(textoJSON); 
// Salida: '{"nombre":"Ana","edad":22}'

// 2. DESERIALIZACIÓN: De Texto a Objeto
let objetoDeVuelta = JSON.parse(textoJSON);
console.log(objetoDeVuelta.nombre); 
// Salida: Ana

2. Códigos de Estado HTTP

  • 200 OK / 201 Created: La petición se ha completado o creado con éxito.
  • 304 Not Modified: Se utilizan los datos en caché porque no han sufrido cambios.
  • 404 Not Found: El recurso no existe o la URL es errónea.
  • 500 Internal Server Error: Fallo interno en el servidor.

3. Manipulación del DOM: jQuery vs Nativo

Anotación de examen: El código nativo es el propio estándar del navegador, mientras que jQuery simplifica la escritura con el símbolo $. 
// 1. Crear un elemento nuevo
let $jqElemento = $("<li>Elemento</li>");                // jQuery
let nativoElemento = document.createElement("li");        // Nativo
nativoElemento.textContent = "Elemento";

// 2. Añadir el elemento al final de una lista
$("#miLista").append($jqElemento);                        // jQuery
document.getElementById("miLista").appendChild(nativoElemento); // Nativo

// 3. Eliminar un elemento de la página
$("#miLista").remove();                                   // jQuery
document.getElementById("miLista").remove();              // Nativo

4. Peticiones Asíncronas (Async / Await)

Anotación de examen: Las promesas son un "justificante" de que se recibirá un dato en el futuro. async / await detiene el flujo hasta obtener la respuesta y permite utilizar return. 
// Función asíncrona para obtener datos mediante una petición
async function obtenerDatos() {
    try {
        // Petición asíncrona con jQuery
        let resultado = await $.ajax({
            url: "url.php",
            method: "GET"
        });
        
        return resultado; // Retorna el dato obtenido
        
    } catch (error) {
        console.error("Ha ocurrido un error en la petición: " + error);
    }
}

// Ejecución de la promesa
obtenerDatos().then(datos => {
    console.log("Datos procesados:", datos);
});
