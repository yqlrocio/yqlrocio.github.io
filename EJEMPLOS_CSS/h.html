Receta de la tortilla francesa

Ingredientes:

  • Huevos
  • Aceite
  • Sal

Preparación:

  1. Calentar el aceite en una sartén
  2. Cascar el huevo y batirlo
  3. Verter el huevo batido en la sartén
  4. Esperar un par de minutos, voltear y volver a esperar.

Servir con mayonesa, tomate o jamón.

📝 Fases del Ejercicio Sigue estas fases en orden. No pases a la siguiente hasta haber completado la anterior. Fase 1: Reestructurar el HTML Tu primer paso no es escribir CSS, sino organizar el HTML. El HTML actual es semántico, pero no es ideal para la maquetación. Necesitas "envolver" las secciones en contenedores
para poder controlarlas. Tu Tarea: Modifica el del HTML para crear una estructura lógica. Pista 1: Necesitarás un contenedor principal que envuelva toda la receta (esta será tu "tarjeta"). Pista 2: Para usar Flexbox más tarde y poner "Ingredientes" y "Preparación" uno al lado del otro, ¿no deberías agruparlos dentro de un
padre común? Pista 3: Piensa en dar nombres de class (clases) a tus nuevos
s para poder seleccionarlos fácilmente en CSS (ej. clase="tarjeta", clase="columnas", clase="col-izquierda", etc. ¡Elige los nombres que te parezcan más claros!). Fase 2: Estilos "Mobile-First" (El Look de la Tarjeta) Ahora, en tu archivo estilo-receta.css, vas a definir los estilos base. Siguiendo el enfoque Mobile-First, estos estilos deben verse bien en una pantalla de teléfono (es decir, todo apilado verticalmente). Tu Tarea: Escribe el CSS para que, en una pantalla pequeña, se vea como una tarjeta unificada. Dale un background-color al (ej. un gris claro) para que la tarjeta contraste. Haz que tu "contenedor principal" (la tarjeta) tenga: Un background-color blanco (#ffffff). Un width máximo (ej. max-width: 800px) y esté centrado en la página (▶️ Pista: margin: 0 auto;). Bordes redondeados (border-radius) y una sombra suave (box-shadow). Estiliza el

para que parezca el encabezado de la tarjeta (ej. con un color de fondo y texto blanco). En este punto, "Ingredientes" y "Preparación" ya deberían estar uno encima del otro por defecto. ¡Perfecto para móviles! Fase 3: La Magia de Flexbox y Media Queries (El Diseño Responsivo) ¡Aquí viene el reto! Queremos que el diseño cambie en pantallas más grandes (tablets y escritorio). Tu Tarea: Añade una Media Query al final de tu CSS para que, cuando la pantalla sea lo suficientemente ancha, el diseño cambie a dos columnas. La Media Query: ¿Cómo escribes la regla @media para que se aplique solo a pantallas que tengan un ancho mínimo (ej. min-width) de 700px? Activar Flexbox: Dentro de esa media query, debes seleccionar el
padre que contiene "Ingredientes" y "Preparación". ¿Qué propiedad display le darás para activar Flexbox? Definir las Columnas: Por defecto, Flexbox las pondrá una al lado de la otra. Ahora, haz que la columna "Preparación" sea más ancha que "Ingredientes". ▶️ Pista: Investiga la propiedad flex. Si le das flex: 1; a Ingredientes y flex: 2; a Preparación, ¿qué ocurre? ▶️ Pista: ¿Quedan las columnas muy pegadas? Investiga la propiedad gap para el contenedor Flexbox. 🌟 Reto Adicional (Bonus) Si has terminado lo anterior, intenta esto: ¿Puedes hacer que el
